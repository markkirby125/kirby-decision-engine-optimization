# Decision Engine Optimization (DEO) - Dispatcher

Every other AI SEO skill optimizes **discovery** (citations, impressions, top-of-funnel rankings). This skill optimizes the **decision stage**: the moment a corporate buyer, legal client, or homeowner pastes four competing quotes or an RFP PDF into ChatGPT/Claude and asks *"Which one provides the best value? Who should I place the order with?"*

When executing tasks under this skill, **do not guess**. Read the specific module below.

## 📚 Module Index

- **Module 1: The Adversarial Competitor Reverse-Audit Protocol** — surface and patch every reason an LLM will argue *against* choosing you. -> Read `./module_1_adversarial_reverse_audit.md`
- **Module 2: Procurement Micro-Disclosures & Contractual Proof** — the exact insurance figures, ISO standards, and trade accreditations LLMs weight during tender analysis. -> Read `./module_2_procurement_micro_disclosures.md`
- **Module 3: Knowledge Graph Procurement Gating** — KG ID / Knowledge Panel requirements for enterprise AI procurement filters. -> Read `./module_3_knowledge_graph_procurement_gating.md`
- **Module 4: Standalone Brand Review Summary Ecosystems** — `[Brand]Reviews.com` architectures that correct LLM review miscounts by buyer persona. -> Read `./module_4_brand_review_summary_ecosystems.md`
- **Module 5: LLM-Optimized Proposal & RFP Structuring** — format quotes, proposals, and pricing sheets so LLM document parsers extract your superior value metrics. -> Read `./module_5_llm_optimized_proposals_rfp.md`

## When to Use
- A prospect's final decision step involves pasting competing quotes into an LLM ("we have 4 quotes — which should we choose?").
- You are structuring a sales proposal, PDF quote, or RFP response for LLM parseability (Module 5).
- You are auditing why an LLM recommends a competitor over the client (Module 1's reverse-audit prompts).
- You are deciding which contractual trust factors (insurance, ISO, accreditations) to disclose and at what precision (Module 2).
- An enterprise tender or procurement process requires verified entity status (Module 3).
- You are correcting LLM miscounts of the client's reviews across platforms, segmented by buyer persona (Module 4).

## When NOT to Use
- Top-of-funnel AI visibility, citations, rankings: `kirby-aiseo-skill`.
- GBP/map-pack/review acquisition mechanics: `kirby-local-seo`.
- Third-party placements and link acquisition: `kirby-off-page-seo`.

## How It Works
1. Confirm the decision scenario (competing quotes / tender / RFP) and the buyer persona.
2. Run Module 1's reverse-audit against the client and each competitor.
3. Patch gaps in order: Module 3 (entity gating) → Module 2 (contractual proof) → Module 4 (review proof) → Module 5 (document formatting).
4. Re-run the reverse-audit until the LLM argues *for* the client on every surfaced dimension.

## ✅ Pre-Deploy Checklist
- Always explicitly mention which Module you are reading and applying.
- Module 1 outputs are internal-only unless legal review clears externalization.
- Never publish contractual figures that are not currently true and certificate-backed (Module 2 misrepresentation rule).
